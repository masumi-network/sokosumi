## Summary

Integrates [Vercel Related Projects](https://vercel.com/docs/concepts/monorepos/related-projects) in both web and core so deployment URLs are resolved from linked projects instead of env-only configuration. Web uses the related **core** project for the Core API base URL; core uses the related **web** project for the web app base URL (Better Auth trusted origin, redirects, job links).

## Key changes

### Web app
- **Dependency:** `@vercel/related-projects` added.
- **Config:** `vercel.json` includes `relatedProjects` (web preprod/mainnet project IDs). Core API URL moved from secrets to public config: `NEXT_PUBLIC_CORE_API_URL` (default `http://localhost:8787`). `CORE_API_URL` removed from `env.secrets.ts`.
- **Core client:** `coreApiBaseUrl` is derived via `withRelatedProject({ projectName: sokosumi-core-preprod | sokosumi-core-mainnet, defaultHost: NEXT_PUBLIC_CORE_API_URL })`. Generated client and chat route use this base URL.

### Core API
- **Dependency:** `@vercel/related-projects` added.
- **Config:** `vercel.json` includes `relatedProjects` (core preprod/mainnet project IDs). `BETTER_AUTH_TRUSTED_ORIGIN` is optional with default `http://localhost:3000` (doc: overridden on Vercel by related web project URL).
- **`getWebAppBaseUrl()`:** New helper in `config/env.ts` using `withRelatedProject({ projectName: sokosumi-web-preprod | sokosumi-web-mainnet, defaultHost: BETTER_AUTH_TRUSTED_ORIGIN })`. Used for trusted origin, login/consent pages, job links in emails, and magic-link redirects.
- **Auth, job-sync, magic-link:** Use `getWebAppBaseUrl()` instead of `getEnv().BETTER_AUTH_TRUSTED_ORIGIN`. Tests mock `getWebAppBaseUrl` and (in job-sync) `@vercel/related-projects`.

### Lockfile
- `pnpm-lock.yaml` updated for `@vercel/related-projects` in core and web.

## Technical details

- **Web:** Project name is chosen from `NEXT_PUBLIC_NETWORK` (Preprod → `sokosumi-core-preprod`, else `sokosumi-core-mainnet`). Core’s `relatedProjects` in Vercel must point to the **web** app projects so core can resolve the web URL.
- **Core:** Project name is chosen from `NETWORK` (Preprod → `sokosumi-web-preprod`, else `sokosumi-web-mainnet`). Web’s `relatedProjects` must point to the **core** projects so web can resolve the core API URL.
- **Local / non-Vercel:** Both apps use the env fallback (`defaultHost`) when related project URL is not available.

## Testing

- **Core:** `pnpm --filter core test --run` (512 tests). Auth, magic-link, and job-sync tests mock `getWebAppBaseUrl`; job-sync also mocks `@vercel/related-projects` so `withRelatedProject` does not throw.
- **Web:** Core client tests updated for `getEnvPublicConfig` and `NEXT_PUBLIC_CORE_API_URL` (port 8787).
- **Manual:** Local runs use env defaults; on Vercel, confirm related project IDs in `vercel.json` match the intended web/core projects and that preview/production use the expected URLs.
