# Chat failures

1. The owner sends Cuso a message in chat while the assistant's usage limit is exhausted.
2. The reply says the assistant has reached its usage limit and can respond again when the limit is raised or resets.
3. The owner can send a new message after the limit is raised or resets.

If a reply fails for an unclassified reason, the owner sees a message inviting them to try again and contact support if it keeps happening. A failed background run also names the work that stopped.

If a reply is cancelled, the owner sees “The reply stopped before it finished.”
