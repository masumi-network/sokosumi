# Full-resolution tiles

The full-resolution images are too large to open in most browsers (and GitHub cannot preview files this big), so they are cut into pieces that open fine. Tiles are lossless crops: put them side by side (row r, column c) to rebuild the original. For a quick look use the previews one folder up: [architecture-preview.png](../architecture-preview.png), [one-pager-preview.png](../one-pager-preview.png).
