## Failed cases

Fail on both versions, with the same checks:

- `cmo-month-*` production (picture-variety, hiltl, blue-bottle-coffee, timed, styled-pictures, linkedin-openings): Month made 0 of N pieces ready; Every Social post written 0 of N; Jev read the month: no review. Core's `write_month_pieces` ran 4 to 5 times in each.
- `cmo-competitor-feed`, `cmo-competitor-second-hand`, `cmo-competitor-digest`: no message to the owner.
- `cmo-seo-weekly-report`, `cmo-seo-before-after`, `cmo-seo-write-article`: no page change, title or article saved.
- `cmo-post-with-picture`: generate_image failed.
- `cmo-tiktok-waits-for-owner`: route DIRECT_RESPONSE, never calls save_strategy.
- `cmo-change-request`: judge fail; the save_strategy calls failed and Cuso didn't retry.
- `cmo-research-utxo-ag`: Brand Brain names the main offer: "utxo AG builds custom software, AI agents and automation…".

Differ between runs:

- `cmo-ads-yes`: judge fail on both versions for the same reasons: a cost-per-click and click forecast made up without keyword data, saved in `ads.expect`, and a second save that sends `calendar: "undefined"`.
- `cmo-seo-article-ideas`, `cmo-seo-skipped-idea`: keyword research is unavailable locally; whether Cuso then calls `save_seo_suggestions` from the SEO tab's earlier numbers varies run to run on both versions.

## Why the failures happened

None comes from cmo-v22. cmo-v22 changes only the strategy skill and the save schema (`monthWriter` is Core's), and every failure above also happens on cmo-v21 in the same environment. The local setup lacks Ably (chat events fail with 401), keyword research and a working picture path, which the production, competitor, SEO and picture cases depend on. Their root cause on this machine was not diagnosed further. The three differing cases fail on both versions at similar rates over three runs each.

Every case cmo-v22 changes passed: all 15 strategy cases, the entry.fyi research case it added, and all six month-writer cases.

## Verdict

Ship behind the version: cmo-v22 is not the hire default and no live Cuso moves until the owner says so. Before making it the default, run the production, competitor and SEO cases on preprod or mainnet, where Ably, keyword research and pictures work.
