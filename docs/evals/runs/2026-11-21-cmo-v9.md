## Why the failures happened

- **Month cases on the earlier cmo-v9 commit.** The scene rule refused 19 saves, some only for "print" or "printed", which name a real object as often as a medium. Pictures were also still being remade when the case ended: the prompt then copied the reference's masthead dates, prices and printer's credits, and the check refused them. Both are fixed on the final commit: "print" left the save rule, and the prompt names that clutter as no-go. The final run had no scene-rule refusals and passed both cases, with 11 of 16 Muse tries passing the style check.
- **`cmo-post-with-picture`.** This fails on both versions and comes from the local harness. On cmo-v9 the styled job exists and succeeded (`soko-bot:01a1fbcd-9ca6…`), but the check's window (`createdAt >= since`) did not count it. On cmo-v8, `generate_image` itself failed. Neither involves the scene rule, which applies only to month saves.

## Verdict

Ship cmo-v9 as a version. Keep it off the hire default and move no Cuso until the full CMO suite has run on it.
